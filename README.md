# LeetCode Problem Solving Repo

This repository is a collection of programming exercises and LeetCode solutions I solved over time.

The main idea is to practice problem solving, keep my solutions in one place, and organize them by difficulty level.

## Concept

- `easy/` contains simpler problems and basic practice.
- `Medium/` contains problems with a higher level of difficulty.
- `Hard/` contains advanced problems that require strong algorithmic thinking and optimized solutions.

Each file represents one solved exercise, so this repo works like a personal archive of coding practice and progress.

## Purpose

This repo helps me:

- improve problem-solving skills
- review solutions later
- track progress across different difficulty levels
- keep all solved exercises organized

## Summary

In short, this is my LeetCode practice repository, built to store solved problems and show the growth from easy exercises to medium ones.
